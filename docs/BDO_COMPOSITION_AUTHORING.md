# BDO 作曲器界面契约（PAZ meta v782）

本文记录游戏作曲 Web UI 中除乐器、奏法和混音效果以外，可用于本工具兼容设计的
设置与交互。它描述的是 **authoring UI 与原生客户端之间的桥接行为**，不是对未验证
v9 二进制字段的猜测。

## 已验证的编辑设置

| 设置 | 游戏界面 | 是否进入作曲 XML |
|---|---|---|
| BPM | 最小 1，默认 120，静态回退上限 200 | `header.bpm` 与试听用 `header.newbpm` |
| 拍号 | `3/4`、`4/4`、`6/8` | 只写 `header.beat=3/4/6` |
| 绘制网格 | `1/4`、`1/8`、`1/16`、`1/32`、`1/64`，默认 `1/4` | 否 |
| 内部吸附 | 移动、缩放和导入后的几何以 `1/64` 为基础步长 | 否 |
| 缩放 | 20%–200%，每次 10%；播放中禁止修改 | 否 |
| 自动滚动 | 播放时开启；用户横向滚动后可关闭 | 否 |
| 音符力度 | 0–127，绘制默认 100 | `onVelocity`、`offVelocity` |

`max_bpm` 会通过 `FromClient_SetMusicLimit` 覆盖静态 200。因此 200 只是未收到运行时
回调时的界面回退值，不是所有账号、地区或等级的硬上限。

拍号的 UI 标签和 XML 数值是 **verified**。但是 XML 只给出一个 `beat` 数值；当前
v9 单字节节拍字段如何表达 `6/8` 的分母，仍缺少逐项游戏保存差分。因此本证据不能
用于解除工具现有的非 `/4` fail-closed 导出限制。

游戏绘制网格是创作便利设置，不是曲谱属性。本工具可以提供相同的五档“游戏网格”
预设，但不能在打开游戏曲谱时据此强制量化已有音符。游戏 authoring UI 自身可吸附到
`1/64`，也不等于 v9 codec 应拒绝其他可无损往返的时间值。

## 账号运行时限制

原生客户端一次下发三个值：

- `codeCount`：JS 用它限制可编辑时间轴的总小节跨度；
- `noteCount`：新增和粘贴前与当前 active instrument 的音符数比较，因此 UI 作用域是
  **每乐器**，不是全曲总音符数；
- `max_bpm`：覆盖 BPM 控件的最大值。

这三个值都不写入作曲 XML，也没有静态表能代替当前账号回调。本工具离线运行时只能：

1. 将 730 保持为 v9 物理轨道分块限制；
2. 将自身的 10,000 等阈值明确称为性能/审阅保护线；
3. 若未来允许用户录入游戏内显示的限额，也只能作为项目外的兼容检查配置，不能冒充
   自动识别的账号权限。

## 播放与定位桥接

游戏预览会提交整份临时 XML，`header` 同时带：

- `bpm`：音符几何所依据的原始 BPM；
- `newbpm`：当前试听 BPM；
- `startTime`：从时间轴定位处播放时的毫秒偏移。

作曲页的“暂停”实际调用 native Stop；继续时重新提交带 `startTime` 的 XML。这个实现
说明游戏桥接支持定位播放，但不要求本工具复制同一技术路径。本工具用音频设备
`suspend/resume` 保证本地连续性仍是正确的；两者只需在用户可见的播放位置与结果上
一致。`newbpm` 和 `startTime` 也不能据此虚构成新的 v9 持久字段。

游戏 v757 作曲页没有循环、节拍器或独奏控制。A–B 循环、参考音频同步与 Solo 可以是
本工具的非破坏性创作功能，但只能保存在工程/运行时状态中。

## 轨道与静音

游戏没有独立的 track mute 字段。扬声器按钮把该乐器的 Volume 设置为 `0`；再次点击
恢复界面默认音量。保存 XML 最终仍只有 `tracks.volume`。

因此本工具应继续区分：

- `M/S`：本地试听状态，不修改正式曲谱；
- 轨道游戏音量 `0–100`：用户明确编辑后写入 BDO；
- 音符 Velocity：音符自身力度，不能用轨道音量覆写。

同一主类型的子乐器切换通过改变 `midiProgramNo` 并移动当前音符集合实现。跨乐器复制
则会删除目标音域无效项并重置为目标默认奏法。本工具应保留现有的非破坏性预检：先列
出越界和奏法冲突，只有用户明确确认后才变更正式音符。

## 音符 XML 与视图状态边界

游戏生成的 `<notes>` 包含：

`audioIndex=0`、`length`、`startTime`、`offVelocity`、`onVelocity`、`noteNo`、
`articulationIndex`。其中时间为毫秒。`audioIndex=0` 是当前 JS 生成值；在没有二进制
差分前，不能把它解释为新的编辑器字段。

缩放、滚动位置、绘制/选择模式、网格档位和选区均不写入作曲 XML。本工具可以将这些
状态保存在自己的项目 schema 或本机设置中，但 BDO 导出器不得为它们增加 wire 字段。

在本次完整 JS/HTML 资源中没有发现 `pan`、`solo`、`loop`、`metronome`、独立 mute、
undo 或 redo 的 authoring 控件/字段。这只证明当前 hash 对应的 v757 页面没有这些功能，
不证明未来客户端或未验证的 native 数据永远不支持它们。

## 可落实清单

- 提供 `1/4` 至 `1/64` 的游戏网格快捷预设，保留自由编辑且不自动量化导入数据；
- 游戏兼容检查按乐器显示音符数，并把账号上限标为“需游戏内确认”；
- 继续将 Mute/Solo/循环/视图透明度作为工程或运行时状态，禁止写入 BDO wire；
- 继续保留单一正式 BPM；变速试听如果实现，应与音符几何变换分离；
- 只有取得 `3/4`、`4/4`、`6/8` 的受控保存差分后，才评估扩展非 `/4` 导出。
